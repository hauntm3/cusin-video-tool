# CUSINI ROYAL VIDEO TOOL

## Как запустить

1. Откройте раздел `Releases`
2. Скачайте файл `CUSINI_ROYAL_VIDEO_TOOL.exe`
3. Запустите его
4. Нажмите `Выбрать файл...`
5. Выберите режим: сжатие, обрезка, квадрат из 2000-х или оптимизация GIF

Результат сохраняется рядом с исходным видео, если не выбрать другой путь вручную.

Для `.gif` есть отдельный режим оптимизации. В нём можно выбрать итоговый размер,
FPS, число цветов, желаемый вес и формат результата (`GIF` или более компактный
`MP4`). При выборе GIF-файла приложение переключается в этот режим автоматически.
GIF также можно обрезать по времени и превращать в квадрат в стиле записей из 2000-х.

## Для разработки

Если нужно запустить проект из исходников:

```powershell
python -m pip install -r requirements.txt
python .\compress_video.py
```

Если нужно пересобрать `.exe`:

```powershell
.\build_exe.bat
```
